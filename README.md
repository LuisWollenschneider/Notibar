# Notibar

A macOS app that creates status bar entries for apps, which don't already have one to display their
notifications in. It can also group multiple apps into a single entry, to save space.

Apps can be opened by clicking their icon in the status bar, and which apps to show / use for grouping
can be configured in the app's settings.

To be as little distracting as possible, notification app entries are grayed out when they have no 
unread notifications, and are shown in color along with a notification badge when they do.
